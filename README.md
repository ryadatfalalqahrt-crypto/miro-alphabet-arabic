# مغامرات الحروف مع ميرو (Miro Arabic Alphabet Adventure)

## محتويات المشروع
- `www/index.html`: كود اللعبة الكامل بجميع المحطات الـ 6 (جزيرة الحروف، بالونات الحروف، قطار الأصوات، سبورة التتبع والتلوين، تحدي النجوم، غرفة الجوائز).
- `package.json` و `capacitor.config.json`: إعدادات تحويل اللعبة لتطبيق أندرويد.
- `.github/workflows/build-apk.yml`: ملف البناء التلقائي لاستخراج ملف `app-debug.apk` عبر GitHub.

## خطوات استخراج ملف APK:
1. أنشئ مستودع جديد (New Repository) على موقع GitHub.
2. ارفع جميع الملفات والمجلدات الموجودة هنا (تأكد من رفع مجلد `.github` أيضاً).
3. افتح تبويب **Actions** في المستودع واضغط **Run workflow**.
4. بعد انتهاء البناء، حمّل ملف **app-debug** من قسم **Artifacts** بالأسفل.
